About CHUBB
CHUBB (Channel Usage Based Backoff) measures each node's transmission ratio:

N_TRatio = N_t / T

Uses this ratio to select an adaptive multiplicative factor G for CW adjustment — unlike BEB which blindly doubles on every collision.

Result: 3–31% throughput improvement in dense WANETs.

Base paper: HCIS Journal, Vol.14, 2024 — KUST Kohat
